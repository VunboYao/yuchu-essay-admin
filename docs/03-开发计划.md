# React Admin 从 0 到 1 开发计划

> 在仓库 `Admin-React/` 用 Vite + React 19 + TypeScript 复刻现有 Vue Admin（`[Admin/](../../Admin/)`）全部**业务能力**。  
> **质量以** `[01-工程契约.md](./01-工程契约.md)` **为准**；本文只负责任务切分。冲突时工程契约赢。  
> 你按步骤实现；每步完成后把代码/疑问发我，我按该步「验收标准」+ 工程禁止项逐项核对。  
> **默认不替你写完整业务**（除非某步明确说「帮我实现」）；Vue Admin 只读对照，不改动。

---

## 目标与约束

- **企业级实现**：业务体量小，规范不降级。禁止 demo / 占位能跑 / 先抄 Vue 再补类型。
- **对等范围**：路由 path、菜单分组、API 路径与字段、业务规则。UX 与数据层按 React 企业级（Query、RHF+zod、`ApiError`），不照搬全局 Loading、拦截器跳转、页内 `load()`。
- **Vue 只当产品说明书**：`[Admin/](../../Admin/)` 随时左右对照字段与交互规则，**不是**实现模板。
- **验收驱动**：每步有勾选清单；`pnpm verify` 必须绿才能过；完成一步再进下一步。
- **与总计划 005 对齐**：开下一阶段的闸门是 **P1-MVP**（Step 1–7：壳、鉴权、`ApiError`、Shared、标签 + 教材分类），不是 11 页刷完。Step 8–16 为对等加分，允许与 P3 预习交叉；质量仍以 01 工程契约为准，不降级。

## 锁定技术栈（与 Vue 对位 + 刻意补 React 缺口）


| 能力    | Vue Admin       | React 选型                                               |
| ----- | --------------- | ------------------------------------------------------ |
| 构建    | Vite            | **Vite 8 + React 19**                                  |
| 语言    | TypeScript      | TypeScript（`strict` + `noUncheckedIndexedAccess`）      |
| UI    | Element Plus    | **Ant Design 6**（中文后台最常见对位）                            |
| 路由    | Vue Router      | **React Router 8**（只负责路由，不 loader 拉数）                  |
| 客户端状态 | Pinia（仅 auth）   | **Zustand + persist**（仅 auth）                          |
| 服务端状态 | 页面内 `ref`       | **TanStack Query v5**（`queryKeys` + `queryOptions`）    |
| 表单    | 手写 + Element    | **react-hook-form + zod**                              |
| HTTP  | axios（拦截器耦合 UI） | axios + **类型化** `ApiError`（与 UI 解耦）                    |
| 富文本   | wangEditor      | **TipTap**                                             |
| 拖拽    | vuedraggable    | **@dnd-kit**                                           |
| OSS   | ali-oss         | ali-oss（业务逻辑对照 `Admin/src/utils/ossUpload.ts`，实现按契约重写） |
| 包管理   | pnpm            | pnpm                                                   |
| 开发端口  | 5173            | **5174**（避免与 Vue Admin 抢端口）                            |
| 质量门   | 仅 type-check    | **Oxlint + type-check**；Vitest 暂缓；`pnpm verify`        |


**刻意不选 Next.js**：当前 Admin 是纯 SPA，Next 的 RSC/SSR 对后台价值低、干扰组件模型。掌握 Vite SPA 后再考虑「可选：迁 Next」。

**刻意不迁**：全局 Loading、`any` 解包、拦截器里 toast/跳转、页内 `load()`。详见 `01-工程契约.md`[「禁止照搬清单」](./01-工程契约.md)。

## Vue → React 心智对照（贯穿全程）


| Vue                      | React（本项目用法）                                 |
| ------------------------ | -------------------------------------------- |
| `.vue` SFC               | `.tsx` + CSS Modules / `shared/styles` token |
| `ref` / 页内 `list`        | 服务端数据 → Query；本地 UI → `useState`             |
| `computed`               | 直接派生或（有证据时）`useMemo`                         |
| `watch` / `onMounted` 拉数 | **禁止**用 Effect 拉列表；用 `useQuery`              |
| `onUnmounted` 清订阅        | `useEffect` cleanup（仅订阅/DOM）                 |
| `provide/inject`         | 仅 app providers；业务态不用 Context 代替 Query       |
| Pinia                    | Zustand（仅 auth）                              |
| Vue Router `beforeEach`  | **AuthGate** 组件                              |
| `v-model`                | RHF `Controller` + Ant 控件                    |
| 插槽                       | `children`                                   |
| `keep-alive`             | 不缓存路由出口；靠 Query `staleTime` 回页仍有数据           |
