提交时请包含：

1. Step 编号与名称

3. 相关文件路径  
4. 卡点 / 与 Vue **业务规则**的对照疑问（实现差异按 01 工程契约解释即可）  

审查维度：

- 该步验收标准是否全部满足  
- 路由 / API 字段 / 业务规则是否与 Vue Admin 对等  
- 是否违反 `01-工程契约.md` 禁止项（演示页、`any`、拦截器 UI、Effect 拉数、全局 Loading 等）  
- 该步 React 技术点是否真正用到  
- `pnpm verify` 是否绿（当前 = lint + type-check；测试不作为本步门槛）

## Step 3 · Auth（AuthGate）

| 项 | 结果 |
|----|------|
| 状态 | 已通过 |
| 日期 | 2026-08-24 |
| 审查结论 | 通过。Zustand `persist`（key `admin_token`）+ AuthGate 声明式守卫 + 登录页只 `setAuth`；zod + RHF + `Controller`；顶栏 username/role；主动退出 `clear({ skipRedirect: true })` 回裸 `/login`。无 token 访 `/articles`、带 `?page=2#body` 的 redirect、登录回跳、刷新保态、已登录访 `/login`、退出后再闯页、后退不再露出业务页，均已手工跑通。`pnpm verify` 绿。 |
| 备注 | RTL 延后 Step 16。登录仍是 mock（3s），Step 4 换真接口。Vue 已登录访 `/login` 一律 `/dashboard`；React 与登录成功共用「安全 redirect」分支（教学文档选定，不是业务规则偏差）。外部 `https://` redirect 按 `parseRedirectUrl` 静态审查 + `/login?redirect=/login` 回退 `/dashboard` 验证，未把外链写进地址栏。 |
