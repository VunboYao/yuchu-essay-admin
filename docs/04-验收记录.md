提交时请包含：

1. Step 编号与名称

3. 相关文件路径  
4. 卡点 / 与 Vue **业务规则**的对照疑问（实现差异按 01 工程契约解释即可）  

审查维度：

- 该步验收标准是否全部满足  
- 路由 / API 字段 / 业务规则是否与 Vue Admin 对等

- 该步 React 技术点是否真正用到  
- `pnpm verify` 是否绿（当前 = lint + type-check；测试不作为本步门槛）
