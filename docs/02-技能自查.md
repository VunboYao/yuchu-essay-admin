## 2. 你已具备（可跳过深学）

这些在 Vue Admin / 现有工程里你大概率已经会，只需记住 **React 侧差异一句**：

| 能力 | React 侧差异 |
|------|--------------|
| TypeScript | 组件显式 props，不用 `React.FC`；本项目 `noUncheckedIndexedAccess` |
| Vite `proxy` / `.env` | 一样；env 经 zod parse，端口 5174 |
| axios 拦截器 | **逻辑不能原样迁**：抛 `ApiError`，禁止拦截器 toast/跳转 |
| CRUD 后台模式 | 表格 + 筛选 + 弹窗；数据层换 Query，表单换 RHF+zod |
| OSS STS 直传 | `ali-oss` 可复用业务规则；交互用 React 状态机 |
| pnpm / 模块化 | 目录改为 `app/` `shared/` `features/`，不要平铺抄 Vue |

## 3. 基础必学包（建议 Step 1 前多数到 L2）

### 3.1 JSX / TSX 与函数组件

- **Vue 对照**：`.vue` template → `return (...)` 的 JSX；`script setup` → 函数体。
- **自查题**：
  1. 为什么属性是 `className` 而不是 `class`？
  2. 如何给组件写 `props` 的 TypeScript 类型？（不要 `React.FC`）
- 掌握：L2

### 3.2 props / children（组合）

- **Vue 对照**：props + 默认插槽 ≈ `props` + `children`。
- **自查题**：写一个 `Card`：标题用 prop，正文用 `children`。
- 掌握：L2

### 3.3 useState

- **Vue 对照**：`ref` / `reactive` → `useState`；改状态必须用 setter。
- **自查题**：
  1. `setCount(count + 1)` 连点三次为何可能只 +1？应用哪种写法修复？
  2. 对象状态更新时为什么常要展开 `{ ...prev, x }`？
- 掌握：L2

### 3.4 useEffect（含 cleanup）

- **Vue 对照**：`onMounted` / `watch` / `onUnmounted` 的**部分**职责；**能不用就不用**。本项目 **禁止** Effect 拉列表。
- **自查题**：
  1. 依赖数组 `[]` / `[id]` / 省略 分别什么意思？
  2. 订阅 / timer 为什么要在 return 的 cleanup 里清掉？
  3. 列表数据为什么不该在 Effect 里 `fetch` + `setList`？
- 掌握：L2

### 3.5 useRef

- **Vue 对照**：`ref` 挂 DOM ≈ `useRef`；也可存「改了不触发渲染」的可变盒。
- **自查题**：何时用 `useRef` 而不是 `useState`？
- 掌握：L2

### 3.6 useMemo / useCallback（默认不用）

- **Vue 对照**：`computed` 常直接算；本项目 **禁止预防性 memo**。
- **自查题**：没有昂贵计算或可感知卡顿时，要不要默认包一层？为什么？
- 掌握：L2

### 3.7 受控 vs 非受控

- **Vue 对照**：`v-model` → 多为 `value` + `onChange`；接 Ant 控件用 RHF `Controller`。
- **自查题**：受控 Input 最少需要哪两个 props？文件上传的 `<input type="file">` 通常为什么偏非受控？
- 掌握：L2

### 3.8 列表渲染与 key

- **Vue 对照**：`v-for` + `:key` → `.map` + `key`。
- **自查题**：为什么不要用数组下标当长期 key（尤其可排序列表）？
- 掌握：L2

### 3.9 条件渲染

- **Vue 对照**：`v-if` / `v-show` → `&&` / 三元 / 提前 `return null`。
- **自查题**：`{count && <Badge />}` 当 `count === 0` 时页面上可能出现什么？
- 掌握：L2

**基础包开干门槛**：上面 3.1～3.9 多数 ≥ L2 → 可以开始 [`03-开发计划.md`](./03-开发计划.md) Step 1。同时已读 [`01-工程契约.md`](./01-工程契约.md) 禁止项。
